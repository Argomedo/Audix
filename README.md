# Audix

App de audio para Android TV y celular, hecha en Kotlin con Jetpack Compose.

## Funciones
- Efectos de audio y ecualizador
- Perfiles de sonido
- Volumen+ (refuerzo de volumen)
- Temas visuales
- Se inicia sola al encender el dispositivo

## Requisitos
- Android 8.0 (API 26) o superior
- Compatible con Android TV (Leanback) y teléfonos

## Compilar
```bash
./gradlew assembleDebug
```
El APK queda en `app/build/outputs/apk/debug/`.

## Descargar
Revisa la sección **Releases** del repositorio para bajar el APK listo para instalar.
